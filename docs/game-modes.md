# Game modes

| Mode | Goal |
| --- | --- |
| Levels | Solve progressively harder unlimited boards. Revisit cleared levels for a better time. |
| Daily Challenge | Solve the deterministic puzzle for the device's local calendar day. |
| Time Attack | Solve as many boards as possible in ten minutes. The timer follows Android elapsed time through backgrounding. |

All three work offline and follow the same wall-free route rules. Eligible Levels and Daily Challenge play earn supply crates. Share the real challenge date, elapsed time and hints from Daily Challenge, the score and solve count from Time Attack, and numbered level milestones from Levels.
