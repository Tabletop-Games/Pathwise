# Play Games

The Android bridge uses Play Games Services v2 for sign-in, native achievement and leaderboard views, and optional online account linking. The backend reads Google's verified player ID only when the player explicitly links an online account. Local gameplay and achievement eligibility work offline.

See [Google Play Games achievements](google-play-achievements.md) for the baseline audit, complete catalog, offline synchronization, Android verification and Console instructions. [Publisher setup](../setup.md#5-before-enabling-play-games) is the external setup checklist. Configured leaderboards open in native read-only views. Authoritative ranked submissions, score proofs, daily online rankings and Play Integrity remain unavailable.
