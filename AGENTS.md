# Pathwise

Pathwise is Android-only. Do not build, test or change iOS, and do not add iOS CI jobs. The `ios/` directory is dormant scaffolding; see [docs/android-only.md](docs/android-only.md).

Read [.agents/agents.md](.agents/agents.md) for development and release instructions and [.agents/project_context.md](.agents/project_context.md) for architecture, gameplay invariants, persistence, and product context.

Run the release and migration checks before proposing changes to gameplay, advertising, or billing. The current release guide is [docs/release.md](docs/release.md).
