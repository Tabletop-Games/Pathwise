# Pathwise

`AGENTS.md` at the repository root is the canonical instruction file and Kiro loads it automatically. Follow it.

Before substantial UI, UX, theme, artwork or animation work, load the `pathwise-design` skill (`.kiro/skills/pathwise-design/`, which points to the canonical `.agents/skills/pathwise-design/SKILL.md`). Do not duplicate its content in steering.

Do not add per-feature specs or audit reports to `.kiro/`. Use pull requests and commit history for history, and `docs/` for current behaviour.
